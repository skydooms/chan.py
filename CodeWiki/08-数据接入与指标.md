# 08 · 数据接入与指标

本篇分两部分：

1. **数据接入**：`DataAPI` 如何把外部行情变成 `CKLine_Unit`，以及如何接自己的数据源；
2. **指标计算**：`Math` 下 6 类指标模型、它们如何写回 K 线、以及如何新增指标。

# 第一部分：数据接入

## 1. 抽象契约 `CCommonStockApi`

源码：[DataAPI/CommonStockAPI.py](file:///workspace/DataAPI/CommonStockAPI.py#L7-L34)

```python
class CCommonStockApi:
    def __init__(self, code, k_type, begin_date, end_date, autype):
        ...
        self.SetBasciInfo()

    @abc.abstractmethod
    def get_kl_data(self) -> Iterable[CKLine_Unit]: ...

    @abc.abstractmethod
    def SetBasciInfo(self): ...

    @classmethod
    @abc.abstractmethod
    def do_init(cls): ...

    @classmethod
    @abc.abstractmethod
    def do_close(cls): ...
```

| 方法 | 职责 |
| --- | --- |
| `__init__` | 保存 5 个参数；立即调用 `SetBasciInfo()` 补齐 `name` / `is_stock` |
| `SetBasciInfo()` | 查询标的元信息（是否股票、名称） |
| `get_kl_data()` | **生成器**，逐根 `yield CKLine_Unit` |
| `do_init()` / `do_close()` | 类级别的连接初始化/释放（登录、登出），由 `CChan.load` 成对调用 |

`CChan.load` 的调用约定（[Chan.py#L196-L214](file:///workspace/Chan.py#L196-L214)）：

```python
stockapi_cls.do_init()
try:
    ...  # 为每个级别各 new 一个实例并消费 get_kl_data()
finally:
    stockapi_cls.do_close()
```

> 注意是**每个级别一个实例**（`get_load_stock_iter` 里 `stockapi_cls(...)`），但 `do_init/do_close` 只在最外层各调一次。所以数据源内部不要假设「一个实例对应一次登录」。

## 2. 内置数据源

### 2.1 数据源枚举与选择

`DATA_SRC`（[Common/CEnum.py#L5-L9](file:///workspace/Common/CEnum.py#L5-L9)）：`BAO_STOCK`、`CCXT`、`CSV`、`AKSHARE`。

选择逻辑 [CChan.GetStockAPI](file:///workspace/Chan.py#L171-L194)：

DATA_SRC.BAO_STOCK → DataAPI.BaoStockAPI.CBaoStock      # 默认

DATA_SRC.CSV       → DataAPI.csvAPI.CSV_API
DATA_SRC.AKSHARE   → DataAPI.AkshareAPI.CAkshare
"custom:模块名.类名" → importlib.import_module(f"DataAPI.{模块名}") → getattr(类名)
其他字符串          → CChanException(SRC_DATA_TYPE_ERR)

### 2.2 BaoStock（`DATA_SRC.BAO_STOCK`）

[DataAPI/BaoStockAPI.py](file:///workspace/DataAPI/BaoStockAPI.py#L57-L114)

| 特性 | 说明 |
| --- | --- |
| 登录 | `do_init()` 里 `bs.login()`，用类变量 `is_connect` 防重复；`do_close()` 登出 |
| 代码格式 | `sh.600000` / `sz.000001` |
| 分钟线字段 | `time,open,high,low,close`（**无成交量**） |
| 日线及以上字段 | `date,open,high,low,close,volume,amount,turn` |
| 复权 | `QFQ→2`、`HFQ→1`、`NONE→3`（BaoStock 的 adjustflag 约定） |
| 周期映射 | `d / w / m / 5 / 15 / 30 / 60` |
| 限制 | 指数没有分钟数据：分钟级别下若 `is_stock=False` 会抛异常 |

时间解析函数 `parse_time_column` 支持 3 种长度：`YYYY-MM-DD`、`YYYYMMDDHHMM00000`(17)、`YYYY-MM-DD HH:MM:SS`(19)。

### 2.3 AKShare（`DATA_SRC.AKSHARE`）

[DataAPI/AkshareAPI.py](file:///workspace/DataAPI/AkshareAPI.py#L51-L141)

| 特性 | 说明 |
| --- | --- |

| 指数判定 | `sh/sz` 前缀 + 数字以 `000/399` 开头 → 指数 |
| 换手率 | 有 `换手率` 列才写入 |

返回的 DataFrame 行由 `create_item_dict` 转为 `CKLine_Unit` 字典，字段包括时间、开高低收、成交量、成交额、可选换手率。

### 2.4 CSV（`DATA_SRC.CSV`）

[DataAPI/csvAPI.py](file:///workspace/DataAPI/csvAPI.py#L43-L87)

- 文件路径：项目根目录下 `{code}_{k_type小写}.csv`，例如 `sz.000001_day.csv`；
- 默认第一行是表头（`headers_exist = True`）；
- 列顺序固定为 `time,open,high,low,close`（成交量/额/换手率在代码中被注释掉，如需可自行打开）；
- 时间字符串支持 10/17/19 长度；
- `begin_date/end_date` 用**字符串比较**过滤；
- 文件不存在 → `SRC_DATA_NOT_FOUND`；列数不符 → `SRC_DATA_FORMAT_ERROR`。

这是**离线测试最方便**的数据源：把 CSV 放到仓库根目录即可。

### 2.5 CCXT（`DATA_SRC.CCXT`）

[DataAPI/ccxt.py](file:///workspace/DataAPI/ccxt.py#L24-L97)

- 固定使用 `ccxt.binance()`；
- `fetch_ohlcv(code, timeframe, since=parse8601(begin_date))`，**`begin_date` 必须是 ISO 日期**（如 `2020-01-01`）；
- 周期映射：`1d/1w/1M/5m/15m/30m/1h`；
- 用 `CKLine_Unit(..., autofix=True)` 构造，容忍交易所返回的异常高低价；
- `parse_time_column` 里 `CTime(..., auto=not kltype_lt_day(k_type))`：**分钟级显式关闭 auto**，避免 0:00 的分钟线被当成「当天结束」。

## 3. 接入自己的数据源

### 3.1 最小实现

在 `DataAPI/` 下新建文件（例如 `MyAPI.py`）：

```python
from Common.CEnum import AUTYPE, DATA_FIELD, KL_TYPE
from Common.CTime import CTime
from KLine.KLine_Unit import CKLine_Unit
from DataAPI.CommonStockAPI import CCommonStockApi

class CMyApi(CCommonStockApi):
    def __init__(self, code, k_type=KL_TYPE.K_DAY, begin_date=None, end_date=None, autype=AUTYPE.QFQ):
        super().__init__(code, k_type, begin_date, end_date, autype)

    def SetBasciInfo(self):
        self.name = self.code
        self.is_stock = True

    def get_kl_data(self):
        for row in my_loader(self.code, self.k_type, self.begin_date, self.end_date):
            yield CKLine_Unit({
                DATA_FIELD.FIELD_TIME:     CTime(row.y, row.m, row.d, row.hh, row.mm),  # 必须 CTime
                DATA_FIELD.FIELD_OPEN:     float(row.o),
                DATA_FIELD.FIELD_CLOSE:    float(row.c),
                DATA_FIELD.FIELD_HIGH:     float(row.h),
                DATA_FIELD.FIELD_LOW:      float(row.l),
                DATA_FIELD.FIELD_VOLUME:   float(row.v),      # 可选
                DATA_FIELD.FIELD_TURNOVER: float(row.amount), # 可选
                DATA_FIELD.FIELD_TURNRATE: float(row.turn),   # 可选
            })

    @classmethod
    def do_init(cls): ...
    @classmethod
    def do_close(cls): ...
```

然后：

```python
chan = CChan(code="xxx", data_src="custom:MyAPI.CMyApi", lv_list=[KL_TYPE.K_DAY])
```

`custom:` 后面的格式是 **`文件名.类名`**（文件必须位于 `DataAPI/` 下）。

### 3.2 必须遵守的 5 条约定

| # | 约定 | 违反后果 |
| --- | --- | --- |
| 1 | 时间必须是 `CTime`，且**严格递增** | `KL_NOT_MONOTONOUS`（错误信息会提示检查 `auto`） |
| 2 | `low <= min(open, close, high)`、`high >= max(...)` | `KL_DATA_INVALID`（或传 `autofix=True` 自动修正） |
| 3 | 分钟级数据若出现 0:00，需 `CTime(..., auto=False)` | 被误判为「当天 23:59」，导致父子级别错位或时间非单调 |
| 4 | 多级别时，次级别数据必须是父级别时间范围内的**子集** | `KL_DATA_NOT_ALIGN` / `KL_TIME_INCONSISTENT`（受 `max_*_cnt` 限制） |
| 5 | 缺量/额数据时相关指标退化为 0 | `macd_algo=volumn/amount/...` 的买卖点全部失效（`Cal_MACD_trade_metric` 返回 0） |

### 3.3 多级别数据不齐怎么办

- 指数没有分钟线：`CChanConfig({"auto_skip_illegal_sub_lv": True})`，框架会删除该级别并继续（[init_lv_klu_iter](file:///workspace/Chan.py#L153-L169)）；
- 次级别少量缺失：调大 `max_kl_misalgin_cnt` / `max_kl_inconsistent_cnt`，或关掉 `kl_data_check`（不推荐）；
- 只想补当天实时 K 线：不用改数据源，直接把 `CKLine_Unit` 通过 `trigger_load` 喂进去（见 [10-增量计算与策略开发](10-增量计算与策略开发.md)）。

> 根 `README.md` 提到的 `extra_kl` 参数在本仓库的 `CChan.__init__` 中**不存在**，请改用 `trigger_load`。

# 第二部分：指标计算

## 4. 指标如何接入计算流程

三个固定步骤：

1. `CChanConfig.GetMetricModel()` 按配置**实例化**指标模型列表（每个级别一份）；
2. `CKLine_List.__init__` 保存为 `metric_model_lst`；
3. 每根新 K 线进来，`CKLine_List.add_single_klu` 第一件事就是 `klu.set_metric(metric_model_lst)`，把结果写回 klu。

因此**所有指标都是增量计算**：模型内部只保留必要的滑动窗口/上一状态，不重算历史。

`set_metric` 的写回映射（[KLine_Unit.py#L119-L134](file:///workspace/KLine/KLine_Unit.py#L119-L134)）：

| 模型 | 写回字段 | 结果类型 |
| --- | --- | --- |
| `CMACD` | `klu.macd` | `CMACD_item` |
| `CTrendModel` | `klu.trend[type][T]` | float |
| `BollModel` | `klu.boll` | `BOLL_Metric` |
| `CDemarkEngine` | `klu.demark` | `CDemarkIndex` |
| `RSI` | `klu.rsi` | float |
| `KDJ` | `klu.kdj` | `KDJ_Item` |

## 5. 内置指标

### 5.1 MACD

[Math/MACD.py](file:///workspace/Math/MACD.py#L4-L29)

```python
CMACD(fastperiod=12, slowperiod=26, signalperiod=9)
```

- `CMACD_item(fast_ema, slow_ema, DIF, DEA)`，其中 `macd = 2 * (DIF - DEA)`；
- EMA 递推：`ema = (2*value + (N-1)*prev) / (N+1)`；
- `DIF = fast_ema - slow_ema`，`DEA` 是对 `DIF` 再做一次 signal 周期 EMA。

这是所有 `macd_algo=area/peak/full_area/diff` 背驰计算的数据来源。

### 5.2 BOLL

[Math/BOLL.py](file:///workspace/Math/BOLL.py#L8-L28)

- 滑动窗口 `N`（默认 20）；
- `MID = MA`，`theta = 总体标准差`，`UP = MA + 2θ`，`DOWN = MA - 2θ`；
- 上下轨用 `_truncate` 把 0 替换成 `1e-7`，避免下游除零。

### 5.3 均线与上下轨 `CTrendModel`

[Math/TrendModel.py](file:///workspace/Math/TrendModel.py#L5-L22)

`CTrendModel(TREND_TYPE.MEAN|MAX|MIN, T)`，对最近 `T` 个收盘价取均值/最大/最小。由 `mean_metrics` 与 `trend_metrics` 配置驱动，主要用于画图（`plot_mean` / `plot_channel`）和特征。

### 5.4 RSI

[Math/RSI.py](file:///workspace/Math/RSI.py#L1-L38)

- 第一根返回 50.0；
- 前 `period` 根用简单平均，之后用 Wilder 平滑：`avg = (prev*(n-1) + cur)/n`；
- `RSI = 100 - 100/(1 + up/down)`，`down == 0` 时返回 100 或 0；
- `macd_algo="rsi"` 时，笔的力度取笔内 RSI 极值。

### 5.5 KDJ

[Math/KDJ.py](file:///workspace/Math/KDJ.py#L8-L35)

- `RSV = 100*(close - LN)/(HN - LN)`，`HN/LN` 为 `period` 内最高/最低；
- `K = 2/3*prev_K + 1/3*RSV`，`D = 2/3*prev_D + 1/3*K`，`J = 3K - 2D`；
- 初始 `K=D=J=50`。

### 5.6 Demark

[Math/Demark.py](file:///workspace/Math/Demark.py)

| 类 | 作用 |
| --- | --- |
| `C_KL` | 精简 K 线（idx/close/high/low） |
| `CDemarkIndex` | 单根 K 线上的序列信息列表，元素为 `{type: setup/countdown, dir, idx, series}` |
| `CDemarkSetup` | setup 序列（默认 9 根）状态机 |
| `CDemarkCountdown` | countdown 序列（默认 13 根）状态机 |
| `CDemarkEngine` | 对外入口：`update(idx, close, high, low) -> CDemarkIndex` |

`CDemarkEngine` 的类常量即配置默认值来源：`DEMARK_LEN=9`、`SETUP_BIAS=4`、`COUNTDOWN_BIAS=2`、`MAX_COUNTDOWN=13`、`TIAOKONG_ST=True`。

开启方式：`CChanConfig({"cal_demark": True, "demark": {...}})`；绘图用 `plot_demark`。

### 5.7 趋势线 `CTrendLine`

[Math/TrendLine.py](file:///workspace/Math/TrendLine.py#L26-L75)

- `Point(x, y)` 与 `Line(p, slope)` 用 dataclass 定义；
- 输入是「隔一笔取端点」的点列（上升段/下降段各取一部分），遍历可能起点，选择**所有点到直线距离之和最小**的那条；
- `TREND_LINE_SIDE.INSIDE` 用笔的起点（支撑线），`OUTSIDE` 用笔的终点（压力线）；
- 只被 `CSeg.update_bi_list` 使用：线段内笔数 ≥ 3 时构建，绘图时通过 `plot_para["seg"]["plot_trendline"]=True` 显示。

## 6. 新增一个指标（以 RSI 为模板）

### 步骤 1：写计算类（`Math/YourMetric.py`）

要求：

- 构造参数即指标参数；
- `add(...)` 接收**原始数值**（不要传 `CKLine_Unit`，避免循环引用），返回指标值或结果对象；
- **增量计算**：内部只保留窗口/上一状态。

```python
class YourMetric:
    def __init__(self, period=14):
        self.period = period
        self.arr = []

    def add(self, close):
        self.arr.append(close)
        if len(self.arr) > self.period:
            self.arr.pop(0)
        return sum(self.arr) / len(self.arr)
```

### 步骤 2：在 `CChanConfig.GetMetricModel` 中注册

[ChanConfig.py#L75-L103](file:///workspace/ChanConfig.py#L75-L103)：

```python
res: List[CMACD | CTrendModel | BollModel | CDemarkEngine | RSI | KDJ | YourMetric] = [...]
if self.cal_your_metric:
    res.append(YourMetric(self.your_metric_cycle))
```

同时在 `__init__` 里读取参数：

```python
self.cal_your_metric = conf.get("cal_your_metric", False)
self.your_metric_cycle = conf.get("your_metric_cycle", 14)
```

### 步骤 3：在 `CKLine_Unit.set_metric` 中写回

[KLine_Unit.py#L119-L134](file:///workspace/KLine/KLine_Unit.py#L119-L134)：

```python
elif isinstance(metric_model, YourMetric):
    self.your_metric = metric_model.add(self.close)
```

之后即可在任意位置使用 `klu.your_metric`。

### 步骤 4（可选）：画图

`CPlotDriver.DrawElement` 增加分支，并实现 `draw_your_metric`（参考 `draw_rsi`，[PlotDriver.py#L743-L752](file:///workspace/Plot/PlotDriver.py#L743-L752)）：

## 8. 本篇小结

- 数据源只需实现 `get_kl_data()` 生成器 + `SetBasciInfo()` + `do_init/do_close`，用 `custom:文件.类名` 挂载；
- 时间必须用 `CTime`、严格递增；分钟级 0:00 数据要 `auto=False`；
- 指标是增量模型，`GetMetricModel` 实例化、`set_metric` 写回；
- 新增指标只需三步：写类 → 注册 → 写回（可选画图）。
