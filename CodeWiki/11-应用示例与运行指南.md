## 1. 环境与安装

### 1.1 版本要求

- **Python ≥ 3.11**（作者要求；计算密集型，3.11 相比 3.8 实测提速约 16%）。

验证环境（本次文档撰写时实际执行）：

```bash
$ python3 -V
Python 3.14.8
$ python3 -c "from Chan import CChan; print('ok')"
ok
```

> Python 3.14 下核心计算与 matplotlib 绘图均可运行；但依赖库（如 `baostock`）对新版 Python 的 wheel 支持可能滞后，生产环境建议 3.11/3.12。

### 1.2 基础依赖

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r Script/requirements.txt
```

[Script/requirements.txt](file:///workspace/Script/requirements.txt)：

```

```

### 1.3 可选依赖

| 依赖 | 何时需要 | 安装 |
| --- | --- | --- |
| `akshare` | `DATA_SRC.AKSHARE`、`App` GUI | `pip install akshare` |
| `ccxt` | `DATA_SRC.CCXT` | `pip install ccxt` |

### 1.4 无法联网 / 没有行情源时

核心计算不依赖具体数据源，两种离线方式：

1. `DATA_SRC.CSV`：把 `{code}_{级别小写}.csv` 放仓库根目录（列：`time,open,high,low,close`）；
2. 直接用 `trigger_load` 喂合成 `CKLine_Unit`（见第 4 节）。

### 3.1 demo1：最小回测逻辑

```python
for chan_snapshot in chan.step_load():
    bsp_list = chan_snapshot.get_latest_bsp()
    if not bsp_list:
        continue
    last_bsp = bsp_list[0]
    if BSP_TYPE.T1 not in last_bsp.type and BSP_TYPE.T1P not in last_bsp.type:
        continue
    cur_lv_chan = chan_snapshot[0]
    if last_bsp.klu.klc.idx != cur_lv_chan[-2].idx:   # 必须是刚确认的分型
        continue
    if cur_lv_chan[-2].fx == FX_TYPE.BOTTOM and last_bsp.is_buy:
        ...  # 开仓
    elif cur_lv_chan[-2].fx == FX_TYPE.TOP and not last_bsp.is_buy:
        ...  # 平仓
```

「`klu.klc.idx == cur[-2].idx`」是所有 demo 的公共套路，避免在结构未确认时交易。

### 3.2 demo3：为什么需要快照

实盘合成 K 线时，「当前这根大级别 K 线」会随小级别变化，而 `trigger_load` 只能追加、不能回退：

```python
chan = copy.deepcopy(chan_snapshot)                 # 回到上一个确定状态
chan.trigger_load({KL_TYPE.K_60M: [klu_60m],
                   KL_TYPE.K_15M: klu_15m_lst_tmp})  # 重新喂到当前
if 60M 已完成: chan_snapshot = chan                   # 固化
```

### 3.3 demo5 / demo6：机器学习链路

- demo5 用 `last_bsp.features` 收集特征，以「该买卖点最终是否仍存在」为 label，导出 `feature.libsvm` + `feature.meta`，训练 XGBoost 存成 `model.json`；
- demo6 加载 `model.json` + `feature.meta`，实盘逐帧按 meta 索引对齐特征并 `predict`。

两者必须在**同一工作目录**下依次运行（demo6 直接读 demo5 产物）。

## 4. 无数据源的最小冒烟测试

不依赖任何行情库，验证「合并 → 笔 → 段 → 中枢 → 买卖点 → 绘图 → 序列化」整条链路（本次撰写时实际跑通）：

```python
import datetime, random
import matplotlib
matplotlib.use("Agg")

from Chan import CChan
from ChanConfig import CChanConfig
from Common.CEnum import AUTYPE, DATA_FIELD, KL_TYPE
from Common.CTime import CTime
from KLine.KLine_Unit import CKLine_Unit
from Plot.PlotDriver import CPlotDriver

chan = CChan(code="test", data_src="custom:csvAPI.CSV_API",
             lv_list=[KL_TYPE.K_DAY],
             config=CChanConfig({"trigger_step": True}), autype=AUTYPE.QFQ)

random.seed(7)
price = 10.0
for i in range(300):
    o = price
    c = max(1.0, o * (1 + random.uniform(-0.03, 0.032)))
    h = max(o, c) * (1 + random.uniform(0, 0.01))
    l = min(o, c) * (1 - random.uniform(0, 0.01))
    d = datetime.date(2020, 1, 1) + datetime.timedelta(days=i)
    klu = CKLine_Unit({
        DATA_FIELD.FIELD_TIME: CTime(d.year, d.month, d.day, 0, 0),
        DATA_FIELD.FIELD_OPEN: o, DATA_FIELD.FIELD_CLOSE: c,
        DATA_FIELD.FIELD_HIGH: h, DATA_FIELD.FIELD_LOW: l,
        DATA_FIELD.FIELD_VOLUME: 1000.0,
    })
    chan.trigger_load({KL_TYPE.K_DAY: [klu]})
    price = c

kl = chan[0]
print("KLC", len(kl), "BI", len(kl.bi_list), "SEG", len(kl.seg_list),
      "ZS", len(kl.zs_list), "BSP", len(kl.bs_point_lst))

CPlotDriver(chan, plot_config={"plot_kline": True, "plot_bi": True,
                               "plot_seg": True, "plot_zs": True,
                               "plot_bsp": True}).save2img("smoke.png")

chan.chan_dump_pickle("smoke.pkl")
print("reload BI", len(CChan.chan_load_pickle("smoke.pkl")[0].bi_list))
```

期望输出（参考值，取决于随机序列）：

```
KLC 222 BI 14 SEG 3 ZS 2 BSP 2
reload BI 14
```

> 如果这段跑不通，说明问题在 Python/matplotlib/项目路径，而不是行情源。

## 5. `App/ashare_bsp_scanner_gui.py`（PyQt6 GUI）

### 5.1 功能

- **批量扫描**：拉取全 A 股实时列表，逐只做日线缠论分析，找出最近 3 天内出现买点的股票；
- **单股分析**：输入代码单独分析并画图；
- **图表展示**：K 线、笔、线段、中枢、MACD、买卖点，支持 matplotlib 工具栏缩放/平移。

### 5.2 结构

```mermaid
flowchart TD
    Main["AkshareGUI(QMainWindow)"] --> LP["左侧面板<br/>扫描控制 / 单股输入 / 买点表 / 日志"]
    Main --> CP["右侧面板<br/>NavigationToolbar + ChanPlotCanvas"]
    Main --> ST["ScanThread(QThread)<br/>批量扫描"]
    Main --> AT["SingleAnalysisThread(QThread)<br/>单股分析"]

    ST -- progress/found_signal/finished/log_signal --> Main
    AT -- finished(CChan)/error --> Main
    Main -- plot_chart --> PD["CPlotDriver<br/>figure 交给 canvas"]
```

| 类 | 行 | 职责 |
| --- | --- | --- |
| `get_tradable_stocks()` | [L54](file:///workspace/App/ashare_bsp_scanner_gui.py#L54-L102) | `ak.stock_zh_a_spot_em()` + 过滤 |
| `ScanThread` | [L105](file:///workspace/App/ashare_bsp_scanner_gui.py#L105-L221) | 遍历股票，逐只 `CChan` 分析并上报买点 |

| `AkshareGUI` | [L295](file:///workspace/App/ashare_bsp_scanner_gui.py#L295-L728) | 主窗口、事件绑定、绘图 |

### 5.3 过滤规则与判定

`get_tradable_stocks` 依次剔除：

1. 名称含 `ST`；
2. 科创板 `688`；
3. 北交所 `8` / `43` 开头；
4. B 股 `200` / `900`；
5. CDR `920`；
6. 成交量为 0（停牌）；
7. 最新价 ≤ 0。

扫描时：

- 数据窗口：最近 **365 天**、日线、`DATA_SRC.AKSHARE`；
- 跳过无 K 线、以及最后一根 K 线距今超过 **15 天**（疑似停牌）的股票；
- `chan.get_latest_bsp(number=0)` 取全部买卖点，筛出 **买点且时间在最近 3 天内**。

GUI 的缠论配置（[get_chan_config](file:///workspace/App/ashare_bsp_scanner_gui.py#L510-L530)）与 `main.py` 基本一致，但关闭日志：`divergence_rate=inf`、`min_zs_cnt=0`、`bs1_peak=False`、`bsp2/3_follow_1=False`——「尽量多出信号」的宽松配置，结果需二次判断。

### 5.4 运行

```bash
pip install PyQt6 akshare
python App/ashare_bsp_scanner_gui.py
```

脚本开头把项目根目录插入 `sys.path`（[L25-L29](file:///workspace/App/ashare_bsp_scanner_gui.py#L25-L29)），可在任意工作目录启动。

注意：

- GUI 强制 `DATA_SRC.AKSHARE`，必须安装 `akshare` 且能访问东方财富接口；
- 批量扫描**串行**，全市场耗时较长；`ScanThread.stop()` 只置标志位，当前股票算完才退出；
- `stock_cache` 缓存已分析结果，切换股票不重复计算；
- 绘图用 `plt.close('all')` 释放旧图，窗口内只保留最新一张。

## 6. 常见报错与处理

| 报错 / 现象 | 根因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: baostock` | 未安装基础依赖 | `pip install -r Script/requirements.txt` |
| `ModuleNotFoundError: akshare/PyQt6/xgboost/ccxt` | 可选依赖未装 | 见 1.3 节 |
| 窗口一闪而过 | matplotlib 交互窗口随程序结束关闭 | Jupyter 运行 / 先 `save2img` / 末尾 `input()` |
| `kline time err, cur=..., last=...` | 时间非严格递增，或分钟级 0:00 被当日线 | 保证升序；分钟级 `CTime(..., auto=False)` |
| `low price=... is not min` / `high price=... is not max` | 数据源高低价异常 | 修数据，或 `autofix=True` |
| `在次级别找不到K线条数超过...` | 次级别缺失 | 补数据；`max_kl_misalgin_cnt`；指数用 `auto_skip_illegal_sub_lv` |
| `父&子级别K线时间不一致条数超过...` | 父级别缺数据 | 补齐；调整 `max_kl_inconsistent_cnt` |
| `最高级别没有获得任何数据` | 代码格式 / 日期范围 / 数据源无数据 | 检查 `code` 与 `begin_time` |
| `RecursionError`（deepcopy/pickle） | `pre/next` 成环 | 用 `chan_dump_pickle` / `chan_load_pickle`，或调高递归上限 |
| 线段看起来不对 | 分型未确认 / 参数不符预期 | 打开 `plot_eigen`；确认 `seg_algo` 与 `left_seg_method` |
| 买卖点「消失」 | 当前帧结构被后续 K 线修正 | 预期行为，见 [10](10-增量计算与策略开发.md#4-is_sure当前帧与信号消失) |
| `unknown para = xxx` | 传了完整版参数 | 本仓库不支持，删掉该参数 |
| `plot_cbsp` 没效果 | 本仓库未实现 cbsp | 用 `plot_bsp` / `plot_segbsp` |
| 动画越来越卡 | `CAnimateDriver` 已知内存泄漏 | 仅作演示，帧数多时改为保存图片 |
