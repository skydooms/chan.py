## 1. 为什么先有 `PlotMeta`

`CChanPlotMeta(kl_list)` 接收一个级别的 `CKLine_List`，把元素拍平成「只有坐标和样式属性」的轻量对象：

| Meta 类 | 对应元素 | 关键字段 |
| --- | --- | --- |
| `Cklc_meta` | `CKLine` | `high/low/begin_idx/end_idx/type/klu_list` |
| `CBi_meta` | `CBi` | `begin_x/end_x/begin_y/end_y/dir/type/is_sure` |
| `CSeg_meta` | `CSeg` | 同上 + `idx` + `tl`（趋势线） |
| `CEigen_meta` | `CEigen` | 矩形 `begin_x/end_x/begin_y/end_y/w/h` |
| `CEigenFX_meta` | `CEigenFX` | 三元素矩形 + `gap` + `fx` |
| `CZS_meta` | `CZS` | `low/high/begin/end/w/h/is_sure/sub_zs_lst/is_onebi_zs` |
| `CBS_Point_meta` | `CBS_Point` | `x/y/is_buy/type/is_seg` + `desc()` |

`CChanPlotMeta` 还预计算：

- `datetick`：每根 K 线的时间字符串，作为 x 轴刻度；
- `klu_len`：原始 K 线总数（x 轴基准，**不是**合并 K 线数）；
- `bi_list / seg_list / segseg_list / zs_lst / segzs_lst / bs_point_lst / seg_bsp_lst`；
- `eigenfx_lst / seg_eigenfx_lst`（特征序列调试）。

三个换算方法用于**次级别联动**：

| 方法 | 作用 |
| --- | --- |
| `sub_last_kseg_start_idx(n)` | 本级别最后 n 段对应的次级别起始 x |
| `sub_last_kbi_start_idx(n)` | 本级别最后 n 笔对应的次级别起始 x |
| `sub_range_start_idx(x_range)` | 本级别最后 x_range 根 K 线对应的次级别起始 x |

> `PlotMeta` 是「换绘图引擎」的关键：接 bokeh / plotly / Web 前端时只需消费这些 meta。

## 2. `CPlotDriver` 构造流程

```python
CPlotDriver(chan: CChan, plot_config=None, plot_para=None)
```

### 2.1 解析 `plot_config`

三种写法等价（[parse_plot_config](file:///workspace/Plot/PlotDriver.py#L28-L61)）：

```python
{"plot_bi": True, "plot_seg": True}
["plot_bi", "plot_seg"]
"plot_bi,plot_seg"
```

`plot_` 前缀可省略（`reformat_plot_config` 自动补，[#L18-L25](file:///workspace/Plot/PlotDriver.py#L18-L25)）。

多级别按级别配置：

```python
{
    KL_TYPE.K_DAY: "plot_kline,plot_bi,plot_seg,plot_zs,plot_bsp",
    KL_TYPE.K_30M: {"plot_kline": True, "plot_bi": True},
}
```

单层字典会复制到所有级别；key 为 `KL_TYPE` 时要求每个级别都存在，否则断言失败。

### 2.2 画布

`create_figure`（[#L85-L129](file:///workspace/Plot/PlotDriver.py#L85-L129)）按 `plot_para["figure"]` 生成 `gridspec`：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `w` / `h` | 24 / 10 | 每个级别基础宽高 |
| `macd_h` | 0.3 | MACD 子图相对高度 |
| `only_top_lv` | False | 只画最高级别 |
| `x_range` | 0 | 只画最后 N 根 K 线（0 = 全部） |
| `x_bi_cnt` | 0 | 只画最后 N 笔 |
| `x_seg_cnt` | 0 | 只画最后 N 段 |
| `x_begin_date` | 0 | 从指定日期（`YYYY/MM/DD`）开始 |
| `x_tick_num` | 10 | x 轴刻度数量 |
| `grid` | `"xy"` | `x` / `y` / `xy` / `None` |

`x_range / x_bi_cnt / x_seg_cnt / x_begin_date` **四者互斥**，同时设置会断言失败（[GetRealXrange](file:///workspace/Plot/PlotDriver.py#L206-L237)）。

> 根 `README.md` 还写了 `x_end_date`，本仓库 `GetRealXrange` **未实现**，传了不生效。

### 2.3 次级别联动

`plot_para["bi"]["sub_lv_cnt"]` 与 `plot_para["seg"]["sub_lv_cnt"]` 用于「在高级别图上高亮最后 N 笔/段对应的次级别范围」，两者**不能同时设置**（[#L170-L175](file:///workspace/Plot/PlotDriver.py#L170-L175)）：

- `bi.sub_lv_cnt = 6`：次级别绘图从「本级别最后 6 笔的起点」开始；
- 被截掉的大级别区域用 `facecolor` + `alpha` 填充提示。

## 3. 支持的绘制元素

| `plot_bi` | `draw_bi` | 笔（虚笔虚线） |
| `plot_seg` | `draw_seg` | 线段（虚段虚线） |
| `plot_segseg` | `draw_segseg` | 线段的分段 |
| `plot_eigen` | `draw_eigen` | 笔的特征序列（调试） |
| `plot_segeigen` | `draw_segeigen` | 线段的特征序列（调试） |
| `plot_zs` | `draw_zs` | 笔中枢（含子中枢） |
| `plot_segzs` | `draw_segzs` | 线段中枢 |
| `plot_macd` | `draw_macd` | MACD 子图 |
| `plot_mean` | `draw_mean` | 均线 |
| `plot_channel` | `draw_channel` | 上下轨 |
| `plot_boll` | `draw_boll` | 布林线 |
| `plot_bsp` | `draw_bs_point` | 形态学买卖点 |
| `plot_segbsp` | `draw_seg_bs_point` | 线段买卖点（`※`） |

| `plot_rsi` | `draw_rsi` | RSI（右侧 y 轴） |

## 4. `plot_para` 详细参数

`plot_para` 是二级字典，key 为元素名，value 直接作为 `**kwargs` 透传给 `draw_*`。**参数名以方法签名为准**。

### 4.1 笔

[draw_bi](file:///workspace/Plot/PlotDriver.py#L344-L377)

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `color` | `'black'` | 颜色 |
| `show_num` | False | 显示笔序号 |
| `num_fontsize` / `num_color` | 15 / `'red'` | 序号样式 |
| `sub_lv_cnt` | None | 次级别只画最后 N 笔 |
| `facecolor` / `alpha` | `'green'` / 0.1 | 截断区域填充 |
| `disp_end` | False | 显示端点数值 |
| `end_color` / `end_fontsize` | `'black'` / 10 | 端点样式 |

### 4.2 线段

[draw_seg](file:///workspace/Plot/PlotDriver.py#L379-L426)

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `width` / `color` | 5 / `'g'` | 线宽/颜色 |
| `sub_lv_cnt` | None | 次级别只画最后 N 段 |
| `disp_end` / `end_color` / `end_fontsize` | False / `'g'` / 13 | 端点数值 |
| `plot_trendline` | False | 画支撑/压力趋势线 |
| `trendline_color` / `trendline_width` | `'r'` / 3 | 趋势线样式 |
| `show_num` / `num_fontsize` / `num_color` | False / 25 / `'blue'` | 序号 |

### 4.3 中枢

[draw_zs](file:///workspace/Plot/PlotDriver.py#L498-L524)

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `color` / `linewidth` | `'orange'` / 2 | 主中枢样式（线宽自动 ≥ 2） |
| `sub_linewidth` | 0.5 | 子中枢线宽 |
| `show_text` / `fontsize` / `text_color` | False / 14 / `'orange'` | 高低点数值 |
| `draw_one_bi_zs` | False | 是否画一笔中枢 |

`draw_segzs` 类似（`color='red'`, `linewidth=10`, `sub_linewidth=4`）。

### 4.4 买卖点

[draw_bs_point](file:///workspace/Plot/PlotDriver.py#L625-L647) / `draw_seg_bs_point`

| 参数 | 默认（笔 / 线段） |
| --- | --- |
| `buy_color` / `sell_color` | `'r'` / `'g'` |
| `fontsize` | 15 / 18 |
| `arrow_l`（箭头占 y 轴范围比例） | 0.15 / 0.2 |
| `arrow_h`（箭头头部占箭头长度比例） | 0.2 / 0.25 |
| `arrow_w` | 1 / 1.2 |

文本由 `CBS_Point_meta.desc()` 生成：买点 `b{type}`、卖点 `s{type}`，线段买卖点带 `※` 前缀。

### 4.5 其他元素

| 元素（`plot_para` key） | 参数（默认） |
| --- | --- |
| `kl` | `width=0.4, rugd=True, plot_mode='kl'` |
| `klc` | `width=0.4, plot_single_kl=True` |
| `segseg` | `width=7, color='brown', disp_end=False, ...` |
| `eigen` / `segeigen` | `color_top='r', color_bottom='b', aplha=0.5, only_peak=False` |
| `macd` | `width=0.4` |
| `mean` | 无参数 |
| `channel` | `T=None, top_color='r', bottom_color='b', linewidth=3, linestyle='solid'` |
| `boll` | `mid_color='black', up_color='blue', down_color='purple'` |
| `rsi` | `color='b'` |
| `kdj` | K/D/J 三条线颜色 |
| `demark` | setup/countdown 颜色、字号、`min_setup`、`begin_line_*` 等 |
| `marker` | `markers`（必须）、`arrow_l=0.15`、`arrow_h_r=0.2`、`arrow_w=1`、`fontsize=14`、`default_color='b'` |

> 注意 `marker` 的箭头头部参数名是 **`arrow_h_r`**（不是 README 的 `arrow_h`），它表示「头部长度占箭头长度的比例」。

`marker` 的 `markers` 结构：

```python
{
    "2023/06/01": ("marker here", "up", "red"),
    "2023/06/08": ("marker here", "down"),      # 用 default_color
}
```

key 可以是 `CTime` 或 `"YYYY/MM/DD"` 字符串；若标注的是父级别 K 线而日期落在次级别，`draw_marker` 会通过 `include_sub_lv_time` 自动把标记下移到对应次级别 K 线（[#L681-L687](file:///workspace/Plot/PlotDriver.py#L681-L687)）。

## 5. 保存与展示

```python
driver = CPlotDriver(chan, plot_config, plot_para)
driver.figure.show()
driver.save2img("test.png")     # plt.savefig(bbox_inches='tight')
```

`save2img` 直接调用 `matplotlib.pyplot.savefig`（[#L287-L288](file:///workspace/Plot/PlotDriver.py#L287-L288)）：

- 无显示环境请先 `matplotlib.use("Agg")`；
- 支持 png/jpg/svg/pdf，由扩展名决定。

## 6. 动画 `CAnimateDriver`

[AnimatePlotDriver.py](file:///workspace/Plot/AnimatePlotDriver.py#L9-L19)

```python
for _ in chan.step_load():
    g = CPlotDriver(chan, plot_config, plot_para)
    clear_output(wait=True)
    display(g.figure)
    plt.close(g.figure)
```

限制：

1. 必须 `CChanConfig({"trigger_step": True})`，否则 `step_load` 断言失败；
2. 依赖 `IPython.display`，**只能在 Jupyter** 中运行；
3. 已知内存泄漏，帧数多时越来越卡（quick_guide 明确说明为实验性功能）。

## 7. 换引擎 / 自定义可视化

1. 用 `CChanPlotMeta(chan[lv])` 拿全部坐标；
2. 自行渲染 `klc_list / bi_list / seg_list / zs_lst / bs_point_lst`；
3. 多级别联动时复用 `sub_last_kbi_start_idx` 等方法换算 x。

不推荐继承 `CPlotDriver`——它深度绑定 matplotlib 的 `Axes`/`Patch`。

## 8. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 图空白 | 无显示后端 / 程序结束即关闭 | `Agg` + `save2img`，或在 Jupyter 运行，或末尾 `input()` |
| 配了 `plot_cbsp` 没反应 | 本仓库未实现 cbsp | 用 `plot_bsp` / `plot_segbsp` |
| `plot_boll` 报错 | 未配置 `boll_n` | 在 `CChanConfig` 设置 `boll_n` |
| `plot_channel` 报错 | `T` 不在 `trend_metrics` | 先配 `trend_metrics`，或 `T=None` |
| `plot_mean` 报错 | `mean_metrics` 为空 | 配 `mean_metrics=[5,20]` |
| 多级别只画了一部分 | `only_top_lv=True` 或 `x_range` 生效 | 检查 `plot_para["figure"]` |
| 次级别没对齐 | `bi.sub_lv_cnt` 与 `seg.sub_lv_cnt` 同时设置 | 只保留一个 |

## 9. 本篇小结

- `PlotMeta` 解耦「结构 → 坐标」，也是换引擎入口；
- `CPlotDriver` 只负责 matplotlib 渲染，`plot_config` 支持字典/列表/字符串/分级别；
- 实际支持 19 个开关，`plot_cbsp` / `plot_tradeinfo` 属完整版；
- `plot_para` 参数名以方法签名为准（如 `marker.arrow_h_r`）；
- 动画仅用于 notebook，有已知内存问题。
